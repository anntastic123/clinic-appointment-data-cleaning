# Clinic Appointment Data Entry and Cleaning Project

## Project Overview
This is a personal Microsoft Excel project demonstrating data entry, data cleaning, and data validation using a fictional clinic appointment dataset.

## Tools Used
- Microsoft Excel

## Dataset
The dataset contains 20 fictional clinic appointment records with fields such as:
- Record ID
- Full Name
- Date of Birth
- Appointment Date
- Department
- Visit Type
- Payment Status
- Amount (NGN)

## Data Cleaning Activities
- Identified and removed an exact duplicate record.
- Standardised names and text formatting.
- Corrected inconsistent department names.
- Standardised visit types and payment statuses.
- Reviewed date formats and missing information.
- Performed data quality checks.
- Documented findings in a cleaning log.
